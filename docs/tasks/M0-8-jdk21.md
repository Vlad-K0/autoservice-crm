# Title: M0-8 Поднять JDK 21 на обеих рабочих машинах

---

**Этап:** M0 — Каркас · **Размер:** S · **Зависимости:** нет · **Выполняет каждый у себя**

## Что делаем

Проект настроен на Java 21 (ADR-0001), а минимум на одной машине стоит JDK 17 — `make run` и компиляция не заработают.

Установка (macOS):

```bash
brew install --cask temurin@21
# или через SDKMAN: sdk install java 21-tem
```

Затем проверить, что Maven видит 21:

```bash
/usr/libexec/java_home -V      # список установленных JDK
export JAVA_HOME=$(/usr/libexec/java_home -v 21)
mvn -version                    # Java version: 21
```

В IntelliJ IDEA: **File → Project Structure → Project SDK → 21** (+ Language level 21).
Джунку JDK на пару проектов: IDEA умеет скачать JDK прямо из этого диалога (Add SDK → Download JDK → Temurin 21).

## Готово, когда

- [ ] `mvn -version` показывает Java 21 у обоих
- [ ] В IDEA проект собирается без ошибок «release 21 not supported»
- [ ] `make test` проходит локально у обоих
- [ ] `make run` поднимает приложение (health = UP)

## Подсказки

- Если нужен параллельно JDK 17 для другого проекта — переключайте через `JAVA_HOME` или per-project SDK в IDEA, глобально 17 удалять не обязательно.
