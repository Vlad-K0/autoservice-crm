# Title: M0-6 Настроить доску GitHub Projects и перенести задачи

---

**Этап:** M0 — Каркас · **Размер:** S · **Зависимости:** нет

## Что делаем

Создаём рабочую доску команды из двух человек.

1. В репозитории: **Projects → New project → шаблон Board**, название «Разработка».
2. Добавляем поля:
   - **Этап** (single select): `M0` … `M7` — совпадает с labels;
   - **Размер** (single select): `S`, `M`, `L`;
   - **Iteration** — двухнедельные итерации (по желанию, для начала хватит статусов).
3. Колонки статусов: **Todo → In progress → In review → Done**.
4. Создаём issues из формулировок в `docs/tasks/` (этапы 0 и 1) и добавляем на доску.
5. В настройках проекта включаем **Workflows**: «Item added to project → Status = Todo» и «PR merged → Status = Done».

## Готово, когда

- [ ] Доска создана и привязана к репозиторию
- [ ] Все задачи M0-5…M1-F1 существуют как issues с labels и полем Этап
- [ ] Задачи распределены по колонкам (в Todo всё, что не взято)
- [ ] Автопереход статусов по workflows включён

## Подсказки

- Формулировки для копирования: `docs/tasks/M0-*.md`, `docs/tasks/M1-*.md` (заголовок — после `# Title:`, тело — после `---`).
- Задачи M0-1…M0-4 уже закрыты — issues для них не нужны, они отмечены в `docs/backlog.md`.
