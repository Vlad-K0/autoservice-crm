# Пул задач (backlog)

**Это мастер-файл проекта:** что сделано, что впереди. Рабочий статус («кто взял,
что в прогрессе») живёт на доске GitHub Projects; этот файл — снимок прогресса,
обновляем на границе итерации (5 минут на недельной синхронизации). Чекбокс
отмечается, когда задача закрыта.

- **Размеры:** S — вечер, M — 1–3 дня, L — неделя (режется на подзадачи при взятии).
- **ID задач** (`M1-2`, `M2-F1`) — указываем в коммитах и PR: `feat: клиенты — CRUD (M1-1)`.
- **Детальные формулировки** задач для GitHub Issues (этапы 0 и 1) — в [tasks/](tasks/README.md).
- **Ссылки на модель:** [oss-crm-survey.md](research/oss-crm-survey.md) — §3 сущности, §3.2 статусы, §4 архитектура.

## Как этот файл связан с GitHub Projects

- Задача в Projects = issue с ID в заголовке (`M1-2 Vehicle: сущность и миграция`).
- Поля доски: **Status** (Todo / In progress / In review / Done), **Этап** (M1–M7), **Размер** (S/M/L).
- Файл не заменяет доску: доска — операционка недели, файл — карта всей дороги.
  Чекбоксы отмечаем при закрытии задач во время синхронизации.
