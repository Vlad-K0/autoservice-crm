# Title: M0-7 ADR-0003: выбор стека фронтенда

---

**Этап:** M0 — Каркас · **Размер:** S · **Зависимости:** нет · **Решение принимается вдвоём**

## Что делаем

Выбираем стек фронтенда и фиксируем решение как ADR-0003 (по шаблону `docs/adr/_template.md`).

Кандидаты (из `frontend/README.md`):

- **React + Vite + TypeScript**
- **Vue 3 + Vite + TypeScript**

Критерии для обсуждения (по убыванию важности для нас):

1. **Знакомство обоих** — на чём быстрее поедем; CRM — это в основном таблицы, формы, календарь.
2. **UI-кит под админки**: таблицы с сортировкой/фильтрами, формы с валидацией, datepicker. React: Ant Design / MUI / shadcn. Vue: PrimeVue / Naive UI / Element Plus.
3. **Генерация API-клиента из OpenAPI** (`openapi-typescript`, `orval` для React; `openapi-typescript` генерик-клиент подходит обоим) — хотим типизированный клиент из контракта бэкенда.
4. Материалы и найм (если проект вырастет).
